# Маленькая книга рецептов

## Как запустить на Windows

1. Распакуй архив в удобную папку.
2. Открой VS Code.
3. Выбери File → Open Folder и открой папку `pixel-recipe-book`.
4. Открой `index.html`.
5. Самый удобный вариант: установи расширение **Live Server** в VS Code, нажми правой кнопкой по `index.html` → **Open with Live Server**.

Можно также просто дважды нажать на `index.html`, чтобы открыть сайт в браузере.

## Что уже работает

- Добавление, редактирование и удаление рецептов.
- Категории и поиск по уже сохранённым рецептам.
- Избранное.
- Пересчёт ингредиентов при изменении количества порций.
- Автоматическое сохранение в браузере через localStorage.
- Адаптивная мобильная вёрстка; на компьютере сайт выглядит как компактное окно.

## Важно

Рецепты хранятся локально в браузере на том устройстве, где сайт открыт. Пока нет регистрации, облачной синхронизации и внешнего поиска рецептов.
